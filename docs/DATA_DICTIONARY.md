# Demo dataset — PyCareer Employee Attendance & Payroll

The `flask seed-demo` command builds *fictional* records in a local SQLite database. No actual PyCareer or SPM India records are included.

| Entity | Expected records after initial seed | Relationship |
|---|---:|---|
| Department | 8 | Employees reference a department |
| User | 201 | One administrator without an employee profile; 200 linked employee users |
| Employee | 200 | Unique `PYC0001`–`PYC0200`; manager pointers reference existing employees |
| Shift | 3 | Employees receive a shift assignment |
| ShiftAssignment | 200 | Each employee assigned to a shift |
| LeaveType | 4 | CL, SL, EL and LOP |
| LeaveBalance | 800 | Four leave categories per employee |
| SalaryStructure | 200 | One active salary structure per employee |
| Attendance | variable | Generated for available weekdays spanning previous month through today; some deliberately absent days |
| PayrollPeriod | 1 | Previous month; status `generated`, not paid |
| PayrollEntry | 200 | One simulated entry per employee, linked to the payroll period |
| Holiday | 3 | Republic Day, Independence Day, Gandhi Jayanti |

Fictional employee names and email addresses (`@pycareer.example`) are safe demo placeholders, not deliverable mailboxes. All demo-user passwords are supplied by your private `.env` file. Additional users receive undisclosed random credentials.

**Payroll disclaimer:** Earnings, deductions and tax percentages are synthetic examples. This is not a compliance-certified payroll system. Do not use these records to disburse salaries.

A compact 200-row CSV preview is provided in `data/pycareer_demo_employees_200.csv`. The full relationships (salaries, attendance, balances, payroll) are generated by the application seed command into SQLite.
