# Deployment Checklist

- [ ] Use a unique 32+ byte secret key from a secret manager.
- [ ] Change database credentials and limit grants to the application schema.
- [ ] Enable HTTPS and HSTS at the reverse proxy.
- [ ] Confirm secure cookies are enabled.
- [ ] Use Redis for distributed rate limiting.
- [ ] Run database migrations and test rollback.
- [ ] Configure automated encrypted backups and restore drills.
- [ ] Remove demo accounts and sample records.
- [ ] Review statutory payroll logic with qualified professionals.
- [ ] Configure centralized logs, monitoring and alerting.
- [ ] Configure retention, access review and employee privacy controls.
- [ ] Run tests and a role-by-role acceptance test.
